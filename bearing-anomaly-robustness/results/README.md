# Results artifacts

This directory contains a curated subset of derived CSV artifacts from the study. It is intentionally not a dump of the full historical CSV archive.

`derived/` contains feature tables, final classical-model results, selected prediction records, bootstrap outputs, OCSVM outputs, and manuscript-level result summaries that are directly relevant to the public scripts or final reported analyses.

The raw Paderborn recordings are not redistributed here. Some deep-learning and detailed failure-characterization CSV outputs referenced by the public scripts were not present in the supplied `csvrecords.zip`; those files are therefore not fabricated or represented as reproducible inputs in this release.
